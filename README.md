# 🎮 Action Game

An interactive action game built using **HTML, CSS, and JavaScript**. This project focuses on creating an engaging gaming experience with animations, keyboard controls, and interactive gameplay.

## ✨ Features

- 🎮 Interactive gameplay
- ⌨️ Keyboard controls
- 🎨 Animated game elements
- 🔊 Sound effects and background music
- 🏆 Score tracking
- 💥 Game over functionality
- 🔄 Restart and replay options

## 🛠️ Technologies Used

- **HTML5** – Game structure
- **CSS3** – Styling, animations, and visual effects
- **JavaScript** – Game logic, keyboard events, and score management
